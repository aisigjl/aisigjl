## ⭐ Featured Projects

### 📈 [QuantAgent](https://github.com/aisigjl/QuantAgent)

基于 **ReAct 与工具调用**的量化分析 Agent，集成行情获取、技术指标分析、金融知识检索与策略回测，支持 CLI 和 Gradio Web 交互。

### 💬 [emotion-support-alignment](https://github.com/aisigjl/emotion-support-alignment)

面向中文情绪支持场景，基于 **Qwen3-4B-Instruct** 实践 **SFT → DPO → 定向安全 DPO**，涵盖数据蒸馏、安全边界设计、LLM-as-Judge 评测与消融分析。

### ⚡ [llm-inference-optimization](https://github.com/aisigjl/llm-inference-optimization)

面向单卡 24GB GPU 的大模型推理基准项目，对比 **Transformers、vLLM 与 INT8 / INT4 量化**，分析不同上下文长度、批大小和并发下的吞吐、延迟、首 token 延迟与显存占用。

### 🧪 [llm-evaluation-framework](https://github.com/aisigjl/llm-evaluation-framework)

面向中文金融问答的模型评测框架，构建 **440 条评测样本**，结合 **LLM-as-Judge、多模型对比、回归检查与失败案例分析**，评估准确性、忠实性、格式遵循、拒答质量与幻觉问题。
